# Apex Retail Group — From Store Rankings to Enterprise Insight

A professional Power BI analytics portfolio project for Apex Retail Group, a UK multi-brand retailer with 60 stores across five regions and three brands.

## Objective

The dashboard moves beyond simple store rankings to analyse revenue, profitability, regional peer performance, target attainment, category margin, Enterprise Zone effects and store-level performance.

## Stakeholders

- **Commercial Director** — store rankings, regional peer comparison and 24-month trends.
- **CFO** — revenue and gross-margin movement and year-on-year comparison.
- **Head of Merchandising** — rolling margin by category and benchmark comparison.
- **Regional Managers** — regional-only performance, rankings and target attainment.

## Dashboard

1. Executive Summary
2. Store Performance & Rankings
3. Margin Intelligence
4. Enterprise Zone Impact
5. Store Profile

## Power BI Features

- Power Query transformation
- Star-schema modelling
- DAX measures
- Time intelligence
- Dynamic field parameters
- What-if parameter

- Report tooltip
- Bookmarks
- Page navigation
